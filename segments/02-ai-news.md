# AI News

## Why this segment exists
Catch me up on what actually happened in AI in the last 24 hours. I want
signal across the full stack — language models, agents, generative media,
voice, and 3D — not "AI is going to change everything" takes. If something
new is meaningfully a cut above the prior best, I want to hear about it
even if it's niche. Open source / open weights matter to me a lot — I'm
specifically watching for projects that are punching above their weight.

## What to cover
Cover anything notable in any of these areas. If multiple categories have
news, give the more impactful ones more time but don't drop the others.

### Language and agent models
- Frontier LM releases, benchmarks, and capability updates (Anthropic,
  OpenAI, Google DeepMind, Meta AI, Mistral, xAI, etc.)
- Agent frameworks and tool-use developments (Claude Agent SDK, OpenAI
  Agents SDK, LangGraph, AutoGen, CrewAI, smolagents)
- Notable research papers when widely discussed

### Open source / open weights (high priority)
- New open-weight releases that approach or beat closed-frontier models
  (Llama, Qwen, DeepSeek, Mistral, Falcon, Nemotron, Yi, Cohere Aya, Phi,
  Granite, OLMo, etc.)
- Open releases that do something cool the closed labs don't yet ship
  (long context, on-device, weird modalities, novel architectures)
- New training recipes, datasets, or eval harnesses released openly

### Image generation
- New image models — Flux, Imagen, DALL·E successors, Midjourney version
  bumps, Stable Diffusion lineage, Hunyuan Image, Recraft, Ideogram
- ControlNet / IP-Adapter / LoRA ecosystem developments worth knowing
- Anything claiming SOTA on identity preservation, prompt adherence, or
  text rendering

### Video generation
- New video models — Veo, Sora, Runway, Kling, Hunyuan Video, Mochi,
  LTX-Video, Wan, CogVideoX, etc.
- Step changes in length, consistency, controllability, or motion realism
- Open-weight video models specifically (huge for me)

### Text-to-speech and voice cloning (high priority)
- New TTS models — ElevenLabs, OpenAI, Cartesia, Sesame, Kokoro, MeloTTS,
  Fish Speech, F5-TTS, MaskGCT, IndexTTS, Higgs Audio, Chatterbox, etc.
- **Real-time / streaming voice cloning is what I most want to hear about.**
  Anything sub-300ms latency, especially open weights, ESPECIALLY if it
  supports zero-shot or few-shot voice cloning. If a model lets me clone a
  voice and speak through it live with low latency, surface it loudly.
- Speech-to-speech models (voice changers, accent conversion)
- Long-context / dialogue / podcast-style TTS (Sesame's CSM, NotebookLM
  Audio Overviews, Dia, etc.)

### Image-to-3D and 3D generation
- New image-to-3D or text-to-3D models — TripoSR, InstantMesh, Hunyuan3D,
  Trellis, Stable Fast 3D, Meshy, Luma, CAT3D, etc.
- Step changes in mesh quality, texture quality, or speed
- Anything that produces game-ready assets out of the box

## Sources to prioritize
- Lab blogs: Anthropic, OpenAI, Google DeepMind, Meta AI, Mistral
- Hacker News front page (filter for substance)
- The Information, Stratechery, Import AI newsletter, AI News (Latent Space),
  Interconnects (Nathan Lambert)
- Hugging Face trending models / spaces / papers
- arxiv-sanity / Papers With Code if a paper is making rounds
- GitHub trending for the day (specifically for open releases)
- Reddit r/LocalLLaMA, r/StableDiffusion, r/MachineLearning when they
  surface a release before mainstream coverage

## What to skip
- Generic "AI will transform X" hot takes
- Funding announcements unless > $100M or strategically interesting
- Twitter drama / personality news
- Repeated coverage of stories I heard yesterday unless there's a real
  update — check segment history

## Format / tone
- Length: ~6-8 minutes spoken (this segment is the show; lean longer if
  there's a lot of real news, shorter if it's quiet)
- Style: two-host conversational. Sam asks the curious "wait, what does
  that mean?" follow-ups; Jordan is excited about what's genuinely new and
  pushes back when something's overhyped.
- Tone: technical-when-it-matters, no hype, but allow genuine excitement
  when a release is actually impressive — don't flatten everything.

## Recurring threads to watch
- Whether on-device / smaller open models are reaching parity with frontier APIs
- Real-time voice cloning quality and latency trajectory (open vs. closed)
- Open-weight video model quality vs. Veo / Sora / Kling
- Image-to-3D mesh quality reaching "actually game-ready" threshold
- Claude Agent SDK adoption and ecosystem
- Real-world enterprise deployment signals (not announcements — actual usage)
