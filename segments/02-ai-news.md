# AI News

## Why this segment exists
Catch me up on what actually happened in AI in the last 24 hours. I want
signal, not hype — concrete releases, papers, and developments, not "AI is
going to change everything" takes.

## What to cover
- Frontier model releases, benchmarks, and meaningful capability updates
  (Anthropic, OpenAI, Google DeepMind, Meta AI, Mistral, etc.)
- Agent frameworks and tool-use developments (Claude Agent SDK, OpenAI
  Agents SDK, LangGraph, etc.)
- Notable open-source releases (especially anything from the Llama / Qwen /
  Mistral lineage)
- Significant research papers if widely discussed

## Sources to prioritize
- Anthropic news, OpenAI blog, Google DeepMind blog
- Hacker News front page (filter for substance)
- The Information, Stratechery, Import AI newsletter
- arxiv-sanity / Papers With Code if a paper is making rounds

## What to skip
- Generic "AI will transform X" hot takes
- Funding announcements unless > $100M or strategically interesting
- Twitter drama / personality news

## Format / tone
- Length: ~3 minutes spoken
- Style: two-host conversational (Sam asks the obvious follow-up; Jordan
  pushes for what's actually new)
- Tone: punchy, technical-when-it-matters, no hype

## Recurring threads to watch
- How Anthropic's Claude Agent SDK adoption is evolving
- Whether on-device / smaller models are reaching parity with frontier APIs
- Real-world enterprise deployment signals (not announcements — actual usage)
